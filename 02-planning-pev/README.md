# 02 计划与逐步检查

复用第 01 篇的虚构样本笔记，比较固定流程、模型列计划后执行、计划执行完后根据轨迹补步骤。脚本用 Python 标准库访问本机 Ollama，默认模型为 `gemma4:e4b`，可用 `OLLAMA_MODEL` 修改。

在项目根目录运行：

```sh
python3 agent-architectures-series/02-planning-pev/experiment.py
```

默认输出九条 JSON 记录，涵盖文件齐全、`runbook.md` 缺失、重试次数改成 3 次三种隔离样本。每条记录含资料目标、逐步搜索与读取结果、检查结论、证据、缺项、模型调用数和耗时。脚本不修改第 01 篇的笔记。

这是针对固定样本的教学实验。`fact()` 只识别样本里的两种句式，不能验证任意中文答案。模型只提出资料目标和搜索词，统一执行器负责搜索、读取及字段检查。模型规划可能因模型版本而变化；固定流程的两个目标由程序预设。自适应路线只在初始计划执行完且仍缺依据时补最多两个目标，对应被分析仓库的重排时机。

2026-10-03 本机单次记录见 `run-v2-2026-10-03.jsonl`。固定路线在齐全和改值样本中取得两项事实，在缺失样本中报告 `retry` 缺项。模型初始计划三次都只列出 `retry`；补步骤路线找回 `timeout`，缺失样本仍报告 `retry` 缺项。每种组合只运行一次，这些观察不能用作模型或架构的总体排名。
