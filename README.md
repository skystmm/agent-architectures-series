所有 `notes/` 文件都是虚构的教学样本。第 01 篇用 Python 标准库访问本机 Ollama，不依赖 LangChain 或 LangGraph。后续篇目会在各自目录保存可独立运行的版本，并说明相对前一篇的变化。

示例用于教学。它们的读文件限制和无证据拒答检查有明确边界，不能仅凭运行成功就部署为生产服务。
