# 01 工具调用与观察后决策

这一目录配套系列第一篇《一个 Agent 为什么会连续调用工具？》。`agent.py` 实现一个普通 Python 工具循环，帮助读者看清模型提出调用、程序执行、结果回传和结束判断。它没有复刻原仓库的 ReAct 双节点图；文章用源码对照解释 ReAct 多出的显式判断步骤。

## 运行条件

- Python 3.10 或更新版本。
- 本机运行的 [Ollama](https://ollama.com/) 服务。
- 一个支持工具调用的 Ollama 模型。本机记录使用 `gemma4:e4b`，可通过 `OLLAMA_MODEL` 选择已安装的其他模型。

在本目录运行：

```sh
python3 agent.py '服务 A 的请求超时设置是多少秒？写在哪份笔记里？'
python3 agent.py '服务 A 的数据库密码是多少？写在哪份笔记里？'
```

第一题在 2026-09-29 的本机运行依次调用 `search_notes`、`read_note`，回答 30 秒并引用 `service.md`。第二题搜索结果为空，程序打印“未读取到笔记依据，无法回答”。模型的查询词和措辞可能随模型与运行环境变化。

## 文件

- `agent.py` 提供两个只读工具、工具声明、Ollama 请求和有限步循环。
- `notes/service.md`、`notes/runbook.md`、`notes/preferences.md` 是虚构样本。

`search_notes` 要求查询中的空格分隔词都出现在文件内容中。它是最简单的文本匹配，不提供语义检索。程序只在成功读取过笔记后允许输出模型回答，并不验证回答每一句是否有原文依据。路径检查、并发、重试和上线验收将在系列后续篇目中逐步处理。
